website
=======

Source for leksah.org / leksah.github.io.

The homepage (index.html, media/) is authored in the main leksah repo at
docs/website/ and mirrored here; edit it there.  /try/ is the in-browser
leksah demo staged by docs/website/try/copy-assets.sh.  The metadata-0.16/
and metadata-0.17/ directories are prebuilt package metadata fetched by
leksah-server — keep them.
